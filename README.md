# 九转戒 (JiuZhuan Jie)

Minecraft 1.20.1 Forge 模组，依赖 Curios API。戒指提供十个轮转位；装备各转物品启用对应能力。自 1.2.1 起，九转戒可在生存模式手动装备或卸下；背包中的戒指不再自动装备。保留不可摧毁、防强制摘取、禁止主动丢弃及装备时死亡保留的规则。

## 1.2.1：手动卸下与补丁兼容

卸下九转戒会关闭轮转槽，将槽内轮转物品返还背包；背包放不下的部分掉落到玩家附近。卸下后各转能力停止，临时护盾和免伤状态清除，累计击杀、永久适应和已有冷却保留。重新装备不会重置成长或冷却。

旧版的“永恒绑定”来自能力逻辑和物品说明，并不是需要单独清除的绑定 NBT。升级后的旧戒指也使用新规则，不需要为此删除物品 NBT。

新版源码已修正 `CurioUnequipEvent` 的处理：拒绝强制摘取使用 `Event.Result.DENY`，不再对不可取消事件调用 `setCanceled`。此前外部 tweaks 中针对相关问题提供的两个 mixin 补丁，对 **1.2.1 新 jar 均不再需要**。切换到新 jar 时，应从外部 tweaks 的 mixin 配置中移除这两个补丁条目，再重新构建 tweaks；这项修改需在外部项目完成。仍使用旧版九转戒 jar 的环境继续保留原补丁。

## 平衡 v1：默认数值

数值由服务端配置管理，并同步到物品说明、背包 HUD 和适应详情界面。下表为默认值，整合包可调整。

| 转生 | 能力 |
| --- | --- |
| 一转·屠戮 | 敌对击杀提高最终伤害，倍率渐近 **2.5 倍**；1000 次获得 90% 的极限额外加成 |
| 二转·辟谷 | 食物低于 18 时每秒补 1 点，最多 18；不补饱和、不清空消耗；饥饿、虚弱时长缩短 20% |
| 三转·洞幽 | 夜视（N 键切换）；失明、黑暗时长缩短 20% |
| 四转·生息 | 战斗中每秒恢复 0.5 生命；脱战 10 秒后每秒恢复 2 生命，受禁疗和治疗减益影响；中毒、凋零时长缩短 20% |
| 五转·凝魄 | 敌对击杀提高最大生命，倍率渐近 **1.3 倍**；1500 次获得 90% 的极限额外加成；独立乘算其他生命成长 |
| 六转·不破 | 常驻 20% 减伤，与十转乘算 |
| 七转·涅槃 | 图腾未能救回时，致命伤恢复至 25% 最大生命，获得 1.5 秒免伤，冷却 180 秒；不清除负面效果 |
| 八转·天眷 | 幸运 +100 |
| 九转·不灭 | 伤后生命预计低于 30% 时，生成 20% 最大生命护盾，立即抵挡本击；持续 6 秒、冷却 90 秒；可被打穿 |
| 十转·万象 | 按伤害类型永久训练，减伤渐近 30%；按有害效果实际暴露时间永久训练，时长缩短渐近 30%；三类伤害成熟解锁脱战飞行，五类成熟达成登神 |

虚空、`/kill` 和明确绕过无敌的伤害不享受本戒指的减伤、护盾或救命。六转与十转默认极限总减伤为 `1 - 0.8 × 0.7 = 44%`。

### 击杀成长

额外加成统一使用 `B(n) = A × (1 - exp(-ln(10) × n / N90))`，最终倍率为 `1 + B(n)`。

- 一转 `A = 1.5, N90 = 1000`；五转 `A = 0.3, N90 = 1500`。
- 佩戴戒指时，玩家归属的敌对生物真实击杀记 1 次，无需提前装备一转或五转。允许刷怪塔；被动生物、宠物、玩家、被取消的死亡不计。
- 默认识别 `Enemy` 敌对生物；模组敌对生物可通过 `nine_turn_ring:growth_hostiles` 实体类型标签补充，`nine_turn_ring:growth_excluded` 可强制排除。
- 五转对不含自身加成的最大生命乘算。例如其他来源提供 100 生命，最终渐近 130；重复装备不会反复放大自身。

### 护盾、救命与时间

按常规减伤、护甲和吸收 → 九转护盾 → 原版图腾 → 七转 → 死亡结算。九转触发时固定盾量，不随生命变化补充、不叠加、不刷新。100 最大生命、35 当前生命时，50 点最终伤害触发 20 点盾，最后剩 5 生命；80 点最终伤害则会打穿并进入后续救命判定。

能力冷却按在线游戏 tick 计算，离线暂停；死亡、换装、跨维度不会刷新。卸下对应物品清除护盾或免伤状态，保留冷却。救命成功不计作真实死亡，不应推进死亡类解锁。

### 永久适应

伤害减伤 `R(n) = 0.30 × (1 - exp(-ln(10) × n / 100))`。每类伤害每 5 秒最多记录一次有效受击：玩家存活，实际扣除生命至少为 **1 生命与最大生命 1% 中的较大值**。零伤、完全由盾吸收、免伤期间和擦伤不计。本次伤害使用受击前的减伤，新成长从下一击生效。

100 次有效受击表示该类型**成熟**，此时减伤 27%；200 次约 29.7%，成熟后仍会成长。三类成熟解锁脱战飞行，五类成熟授予登神进度。攻击命中或受击（含护盾吸收）进入 20 秒战斗状态，立即停用戒指授予的飞行；空中获得 3 秒缓降。戒指只撤销自身授予标记下的飞行，不接管创造、旁观和预先存在的飞行。多个模组同时修改原版共享飞行能力时的所有权交接仍需整合包验证。

有害效果缩时 `E(T) = 0.30 × (1 - exp(-ln(10) × T / 300))`，`T` 为实际承受的累计秒数。累计 300 秒获得 27% 缩时，600 秒约 29.7%。仅在外部施加或刷新时缩短一次时长，不持续乘算剩余时间、不降低等级、不处理瞬时和无限时长效果。持续刷新的光环仍然有效。二、三、四转专长与十转取较大值，不相加。

不存在适应满层后取消攻击、销毁弹射物、取消击退、移出爆炸、自动灭火、无限氧气或清除冰冻/负面的能力。适应详情保留双栏滚动，显示次数、成熟状态、暴露秒数、减伤/缩时百分比及渐近极限；悬停查看完整信息及记录冷却，右键切换已记录的适应项。

## 获取方式

- 一转：首个箱子；二转：饥饿死亡 1 次；三转：黑暗环境死亡 3 次；四转：中毒/凋灵状态死亡 4 次。
- 五转：击杀凋灵；六转：魔法/虚空/真实伤害死亡 3 次；七转：图腾庇佑周期内实际死亡 3 次，每次需重新触发图腾。
- 八转：钓到垃圾 5 次；九转：首次击杀末影龙后，出现在龙蛋上方；十转：装备一至九转并完成前置进度。

## 旧存档迁移

首次载入旧数据时执行一次版本化迁移：保留击杀数；伤害适应每旧层折算 1 次受击，负面每旧层折算 5 秒暴露。旧冷却按剩余比例转换，已有免伤剩余最多保留 1.5 秒。已获进度和已解锁飞行保留，飞行遵守新的战斗限制。迁移之后使用在线计时，不因重登再次迁移或重置能力。

## 构建与验收

### GitHub 自动构建

推送分支或标签、提交 PR 时，GitHub Actions 的 **Build JAR** 工作流会使用 Java 17 和仓库自带的 Gradle 7.6.1 Wrapper 执行 `build`，运行测试并生成经过 Forge 重混淆、可放入 `mods` 的 jar。工作流合入默认分支后，也可在 Actions 页面点击 **Run workflow** 手动构建所选分支。

下载入口：[Actions → Build JAR](https://github.com/BitterOrange/Nine-Turn-Ring/actions/workflows/build.yml)。打开一次成功运行，在 **Artifacts** 下载 `nine-turn-ring-<提交 SHA>`，解压后取出 `nine_turn_ring-<版本>.jar`。jar 保留 30 天，测试报告保留 7 天；过期后可重新运行构建。流程不自动创建 Release，也不需要额外配置发布密钥。

### 本地构建

使用 Java 17：

```bash
./gradlew build
```

Windows 可执行 `./gradlew.bat build`。产物位于 `build/libs/`。

自动检查关注数值曲线边界、成长饱和、迁移与核心伤害结算；具体已执行范围及结果以本次构建/测试输出为准。本轮没有游戏截图或实机验收结果；以下整合包内行为仍需在实际游戏环境验证，不能用编译成功替代：

- 外部生命修饰符叠加，换装后不会递归增长。
- 护甲与吸收后的九转触发、单击打穿护盾、图腾优先和七转冷却。
- 禁疗与治疗倍率影响四转；负面重复刷新不瞬间消失、无限时长和瞬时效果不被缩时。
- 换装、死亡、重登、跨维度不能刷新冷却；离线不推进冷却。
- 生存模式手动卸下戒指，等待多轮 tick 后仍留在背包；退出重登后也不会自动戴回。
- 带有轮转物品时卸下戒指，确认轮转返还背包、槽位关闭、能力停止；重新装备后没有复制、丢失或旧护盾恢复。
- 背包装满时卸下戒指，确认放不下的轮转物品正常掉落，背包、饰品槽和地面物品总数不变。
- 战斗停飞、缓降，以及创造、旁观、其他模组飞行兼容。
- 同阶段 Boss 战有容错，连续失误仍能耗尽救命能力并死亡。
